# Architecture Decision Records

Architecture Decision Records (ADRs) capture important architectural decisions along with their context and consequences.

## How to Create an ADR

1. Copy `template.md` to a new file: `NNNN-short-title.md`
2. Fill in the sections: Status, Context, Decision, Alternatives, Consequences.
3. Submit as part of a pull request with the related code change.
